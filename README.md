# 2025 범죄 안전 지도

인구 10만 명당 범죄 발생 건수를 전국 평균과 비교해 시도·시군구 지도에 색칠한 인터랙티브 지도입니다. 안전한 곳일수록 연한 초록, 범죄가 많은 곳일수록 검붉은색으로 표시됩니다.

**바로 보기:** GitHub Pages로 배포된 `index.html`을 열면 됩니다.

## 기능
- 시도 지도에서 시도를 누르면 시군구 지도로 확대됩니다.
- 전국 시군구 지도도 볼 수 있습니다.
- 범죄 종류(대분류 15개)별로 지도를 다시 칠할 수 있습니다.
- 지역을 누르면 다음 내용이 나옵니다.
  - 인구, 발생 건수, 10만 명당 건수, 전국 대비 배수
  - 가장 많이 일어난 범죄 5가지(이모티콘)
  - 시도 대표 사진

## 데이터 출처

  - 2026년 10월 31일 기준입니다.
- **경계**: 통계청 2018년 시군구 경계 ([southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps))

## 해석할 때 주의할 점
- **유동인구 효과**: 범죄는 발생 장소 기준이고 인구는 거주 인구 기준입니다. 그래서 유동인구가 많은 도심과 관광지는 값이 높게 나옵니다.
- **인천 중구·동구**: 2026년 행정구역 개편으로 인구를 나눌 수 없어 하나로 합쳐 계산했습니다.
- **인천 서구**: 인구는 서해구와 검단구를 더한 값입니다.
- **기타 범죄**: 경찰청 원자료에서 세부 종류가 없는 '기타 범죄'는 범죄 순위에서 뺐습니다.
